# Đặc tả tham chiếu còn giá trị

Các tệp này giữ yêu cầu nghiệp vụ/UI và checklist chưa được nghiệm thu đầy đủ. Chúng không phải nguồn xác định API/mode hiện tại; trạng thái theo ngày trong nội dung cũ phải đối chiếu [tổng quan](../PROJECT_SUMMARY.md), [role](../README.md) và [backlog](../BACKLOG.md) trước triển khai.

| Tài liệu | Dùng khi |
| --- | --- |
| [Design](DESIGN.md) | Token/visual migration và QA chung |
| [Public](PUBLIC_WEBSITE.md) | Copy, layout, thông tin sản phẩm |
| [Parent](PARENT_UI_UX.md) | Dashboard theo bé và màn hình gia đình |
| [Admin](ADMIN_UI_UX.md) | Tables/forms/workflow quản trị |
| [Content Manager](CONTENT_MANAGER_UI_UX.md) | Catalog, metadata, role, quiz/vocabulary, assets |
| [Story Editor](STORY_EDITOR_UI_UX.md) | Canvas, panels, save/dirty, responsive |
| [Animation](STORY_EDITOR_ANIMATION.md) | Timeline/presets/keyframes/playback còn mở |
| [Truyện mẫu](STORY_EDITOR_SAMPLE.md) | Kịch bản Garden Gift cho dựng và kiểm tra |

Không cần đọc toàn bộ thư mục trong chat mới. Chỉ đọc mục màn hình liên quan; API đề xuất trong specs là yêu cầu nghiệp vụ, không tự thêm vào allowlist.
